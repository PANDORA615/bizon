# RFC Horror — прогулка по карте в Unity 6

Это отдельный **Unity-проект**. Blender для запуска не нужен. Все три блока карты и текстуры уже входят в проект.

## Как запустить

1. Скачай `RFC_Horror_Unity6.zip` из корня репозитория и распакуй архив.
2. Открой **Unity Hub → Projects → Add → Add project from disk**.
3. Выбери папку **UnityProject** — ту, внутри которой лежат `Assets`, `Packages`, `ProjectSettings`.
4. Выбери **Unity 6.0.62f1 или более новую Unity 6**. Если у тебя новее версия, выбери её через версию редактора в Hub и подтверди обновление проекта. Если редактор старее 6.0.62f1 — сначала обнови его через Hub. Unity 2022 для этого проекта не используется.
5. При первом открытии дождись загрузки пакетов и компиляции. Нужен интернет к Unity Package Registry. Если Input System попросит перезапустить Editor — согласись.
6. Открой **Assets → RFC → Scenes → RFC_Walk.unity**. Также есть меню **RFC → Open Walk Scene**.
7. Нажми **▶ Play** вверху Editor. Дождись загрузки моделей и коллайдеров; во вкладке **Game** появится склад.
8. Кликни внутри Game для управления.

До Play геометрия в Scene не показана: карта загружается из локальных GLB во время запуска. Это ожидаемое поведение. В Hierarchy во время Play появятся блоки, коллайдеры и персонаж.

## Управление

- **W A S D / стрелки** — ходить.
- **Мышь** — смотреть.
- **Shift** — бежать.
- **Space** — прыгать.
- **F** — фонарь.
- **N** — переключить день/ночь.
- **Esc** — освободить курсор; клик в Game — вернуть управление.
- **H** — скрыть/показать подсказки.
- **F5** — включить/выключить отсечение удалённых объектов для диагностики.
- **Ctrl+R** — восстановиться в последней точке, где персонаж стоял на поверхности.

Старт — B01, основной проход, координаты Blender `[66,160,0.12]`. Скорость шага 2,5 м/с, бега 7 м/с. Масштаб склада сохранён, поэтому переходы между блоками длинные. Настройки: `Assets/StreamingAssets/RFC/walk_settings.json`.

## Что входит

- Runtime-импорт трёх GLB с упакованными PBR-текстурами через **Unity glTFast 6.21.0**.
- **14 040 BoxCollider**, включая **52 наклонных коллайдера лестничных пролётов**. Решётчатые полы получают сплошные коллайдеры независимо от прозрачности материала. Центры 5 424 коллайдеров исправлены по реальной геометрии GLB. Семь панелей крыши, отсутствовавших в GLB из-за скрытой коллекции Blender, восстанавливаются из исходных габаритов.
- **CharacterController**: высота 1,8 м, радиус 0,35 м, ступень 0,2 м, уклон до 35°; гравитация, прыжок, бег, мышь.
- Input System **1.20.1**, встроенный рендер Unity **Built-in**. URP/HDRP устанавливать или конвертировать материалы не нужно.
- Дневное/ночное окружение, фонарь и максимум 12 локальных источников света, выбранных возле игрока.
- Отсечение рендереров по секторам для уменьшения числа видимых объектов. Общие полы и стены сохраняются. **Это не стриминг:** все три блока и коллизии остаются в памяти.
- Проверка контрольного положения пола после импорта каждого блока, чтобы ошибка ориентации не оставила модели отдельно от коллайдеров.

Файлы `Block_01.glb.bytes` и другие — исходные GLB с дополнительным расширением `.bytes`, чтобы Editor не импортировал те же 3D-модели второй раз. Runtime-импортёр читает GLB-заголовок и загружает их как бинарный glTF.

Координаты физики: `(x,y,z) Blender → (x,z,y) Unity`. glTFast отражает X; родитель визуального блока повёрнут на 180° по Y. Повороты коллайдеров преобразуются через quaternion, а не перестановкой углов Euler. Для решётки включается alpha cutout с записью глубины.

## Если возникла проблема

- **Ошибка компиляции**: Window → General → Console. Пришли текст **первой красной ошибки**. До её устранения Play не работает.
- **Остановка на загрузке**: ошибка показывается в Game; полная причина — в Console. Проверь, что распакован весь проект и в StreamingAssets/RFC есть все три `glb.bytes` и JSON.
- **Розовые материалы**: проект должен использовать Built-in. Открой именно приложенный проект вместо копирования скриптов в существующий URP/HDRP-проект. Для сборки есть меню RFC → Include Runtime Shaders.
- **Медленно**: уменьши размер окна Game и `renderDistance` до 96 в `walk_settings.json`, затем перезапусти Play. Не отключай отсечение через F5. Целевой FPS и память на твоём ПК ещё не измерены.
- **Курсор не двигает камеру**: кликни в Game; Esc освобождает курсор.

## Проверки и пределы

Unity Editor в среде подготовки отсутствовал. **Компиляция Unity, Play Mode, ходьба по лестницам, импорт материалов на GPU и standalone-сборка здесь НЕ запускались.** Поэтому это подготовленный проект для первого запуска и проверки, а не подтверждённая работающая сборка игры. Отчёт: `VALIDATION.json`.

Выполнены проверки исходных GLB/JSON, метафайлов и GUID, C#-синтаксиса и математического совмещения визуальных моделей с коллайдерами. Они не заменяют запуск Unity. Хоррор-AI, задания, мультиплеер, сервер смен, LOD и потоковая подгрузка в эту прогулочную версию не входят.

Изменение освещения сделано для читаемости прогулки, без расчёта физически точного света. Тени в реальном времени отключены. Поведение прозрачной решётки и производительность надо проверить на твоём ПК.
